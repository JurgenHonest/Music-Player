# 🎶 Music Player App

A **modern, sleek, and responsive** music player built using **HTML, CSS, and JavaScript**. This app supports **song playback, progress tracking, and interactive controls**, providing an engaging music experience with a stunning UI.

---

## 🚀 Live Demo  

🎵 **Try it Now:**   [Live Demo](https://music-player-by-s.netlify.app/)  

_(Experience seamless music playback with intuitive controls!)_  

---

## 🌟 Features  

✅ **Play, Pause & Toggle** – Smooth playback controls  
✅ **Next & Previous Song Navigation** – Easily switch between tracks  
✅ **Dynamic Progress Bar** – Automatically updates with the song, supports manual adjustment  
✅ **Loop & Shuffle Mode** – Enhance your listening experience (optional)  
✅ **Responsive Design** – Works flawlessly on desktops, tablets, and mobile devices  
✅ **Custom UI Effects** – Glowing border effect for a modern and stylish feel

## 🔧 Installation & Usage  

1. **Clone this repository:**  
   ```
   git clone https://github.com/your-username/music-player-app.git
   cd music-player-app
   ```
2. Navigate to the project folder:
   ```
   cd music-player-app
   ```
   Open the index.html file in your browser to see the music player in action

---

## Usage 🎧
- **Play/Pause**: Click the play button (▶️) to play the song, and click again to pause.
- **Next/Previous Song**: Use the next (⏭️) and previous (⏮️) buttons to navigate between songs.
- **Progress Bar**: The progress bar updates automatically as the song plays. You can manually adjust the progress by dragging the slider.
