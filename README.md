# Music Player App 🎶

A sleek and responsive music player built using HTML, CSS, and JavaScript. It supports song playback with basic controls, including play, pause, next, and previous song functionality. The player also includes a progress bar that updates automatically as the song plays, and users can manually adjust the progress of the song.

## Features 🌟

- ▶️ Play, pause, and toggle between songs.
- ⏮️ Next and previous buttons for song navigation.
- 🎚️ Progress bar that updates automatically and can be manually adjusted.
- 📱 Responsive design that works across various devices.
- ✨ Beautiful UI with a glowing pink effect for the container border.

## Technologies Used ⚙️

- **HTML**: For the structure of the player.
- **CSS**: For styling the UI.
- **JavaScript**: For interactivity and functionality.

## Installation 💻

1. Clone this repository:
   ```
   git clone https://github.com/your-username/music-player-app.git
   ```
2. Navigate to the project folder:
   ```
   cd music-player-app
   ```
   Open the index.html file in your browser to see the music player in action

## Usage 🎧
- **Play/Pause**: Click the play button (▶️) to play the song, and click again to pause.
- **Next/Previous Song**: Use the next (⏭️) and previous (⏮️) buttons to navigate between songs.
- **Progress Bar**: The progress bar updates automatically as the song plays. You can manually adjust the progress by dragging the slider.
